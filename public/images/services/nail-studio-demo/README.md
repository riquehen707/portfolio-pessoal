# Assets do case Tinta

Imagens geradas em 2026-09-30 com a ferramenta de geração de imagens da OpenAI para o projeto demonstrativo fictício **Tinta — estúdio de unhas**.

- `hero-manicure.webp`: aplicação de esmalte em bancada clara;
- `trabalho-ferrugem.webp`: manicure curta em nude e ferrugem;
- `trabalho-vinho.webp`: manicure vinho com traço claro;
- `trabalho-cacau.webp`: composição de mãos em tons de cacau;
- `estudio.webp`: bancada demonstrativa do estúdio.

As imagens não representam clientes, profissionais, endereço, trabalho realizado ou negócio real. Não contêm marcas ou fotografias fornecidas pela referência visual.
